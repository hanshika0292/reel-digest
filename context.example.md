## My goals, in the order the digest should weigh them
Every reel is judged against these. One reel can serve several. Give each goal a short bold label: the digest uses
it to tag reels. Mark a goal "(always flag)" when every related reel should be flagged, even a weak match. This
works well for anything with deadlines.

1. **Newsletter**: a weekly newsletter about home cooking, about 2,000 subscribers.
   - Useful: growing signups, repurposing issues into short videos, cheaper email tooling.
2. **Freelance**: more leads, conversations and booked calls for my freelance web design work for small businesses.
3. **Side app**: a habit-tracker web app, getting ready for a beta and a Play Store launch.
   - Useful: beta-tester recruiting, store listing, launch posts, analytics.
4. **Funding** (always flag): grants, accelerators, startup credits and competitions for any of the above.
   Always note the deadline and eligibility.

## My stack / what I already have
- Mac, Claude Code, Gmail, Google Calendar, Google Drive, a Vercel account.
- Comfortable having Claude Code write and run code for me.

## What I want from these reels
- Workflows that save me time or move one of the goals above: lead capture, outreach, email, content repurposing,
  research, app launch and testing, personal productivity.
- Prefer cheap or self-hosted tools over new monthly subscriptions, unless the time saved is obvious.
- Every link the reel points to (GitHub repo, plugin, MCP server, template, product page), so I don't have to
  hunt for it.

## Things to skip
- Pure hype, or "comment X for the link" reels with no real method in them. Say so and move on, but still give
  me the link if the tool or repo is named or visible.
